Clinic Management System

A desktop-based Clinic Management System developed using C# Windows Forms and SQL Server. The system is designed to help clinics manage their daily operations by organizing patient information, doctor records, appointments, medical records, and treatment data through an easy-to-use graphical interface.

📌 Project Overview

The Clinic Management System provides a centralized solution for managing important clinic data. Instead of maintaining patient and appointment information manually, the system allows users to store, retrieve, update, and manage records through a structured application connected to a SQL Server database.

The project demonstrates practical use of C# programming, Windows Forms, Object-Oriented Programming concepts, database management, SQL queries, and CRUD operations.

✨ Main Features

- 👤 Patient Management
  
  - Add new patients
  - View patient information
  - Update patient records
  - Delete patient records

- 👨‍⚕️ Doctor Management
  
  - Store doctor information
  - Manage doctor records
  - Update and delete doctor data

- 📅 Appointment Management
  
  - Create and manage appointments
  - Connect appointments with patients and doctors
  - View appointment information

- 🏥 Medical Records
  
  - Manage patient medical information
  - Store and retrieve medical records

- 💊 Treatment Management
  
  - Manage treatment-related information
  - Associate treatments with patient records

- 🗄️ Database Management
  
  - SQL Server database integration
  - Data storage and retrieval
  - CRUD operations
  - SQL queries for managing clinic information

🚀 How to Run

1. Clone the Repository

git clone https://github.com/mahmoudtrazi/Clinic-Management-System.git

2. Open the Project

Open the project/solution file in Visual Studio.

3. Configure SQL Server

Make sure SQL Server is installed and running.

Create or restore the required database and update the application's database connection string to match your SQL Server configuration.

4. Build the Project

In Visual Studio:

Build → Build Solution

5. Run the Application

Press:

F5

or select:

Debug → Start Debugging

🗄️ Database

The application uses SQL Server to store and manage clinic data.

The database is responsible for handling information related to:

The application communicates with the database through SQL queries and database connections.
